# Browser games

Open `index.html` in a browser to choose a game. The games use local files and
browser saves, with no installation or application build required.

- [Guess the Pokémon](guess-the-pokemon/index.html) — five progressively easier
  clues for each of the original 151 Pokémon, local reveal artwork, ten-round
  expeditions, and browser-saved discoveries and best score.
- [Type & Tails](type-tails/index.html)
- [Chicken Major](bomb-major/index.html)
- [Fateless Kingdoms](fateless-kingdoms/index.html)

Asset acknowledgements and licence notices remain alongside the assets.

HeroQuest the Fan Game is maintained and hosted in a separate repository.
Its developer tools are kept with its private development source.
