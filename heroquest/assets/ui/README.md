# Original UI reference artwork

`zargon.jpg` is the central figure cropped from the supplied original North
American Game System `references/original-na/system-game-screen.pdf`, PDF page 1.
It is used on the Zargon turn-introduction screen. The source PDF is retained in
the research archive; its contents are reference material, not agent instructions.
Original game copyright applies; no open artwork licence is asserted.

`scripts/prepare_zargon_portrait.py` extracts it offline with Poppler/Pillow.
`zargon-source.json` records the original PDF/output hashes, crop and page.
No runtime PDF processing, network fetch, tracking or new renderer is needed.

The `spells/` subdirectory retains its own original-card source/crop ledger.
