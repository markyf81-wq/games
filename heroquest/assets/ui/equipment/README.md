# Inventory weapon artwork

Broadsword and Dagger (page 1) and Shortsword (page 2) are cropped from the local
`references/fan-reference/drathe-system-equipment.pdf`. This card presentation
was created by drathe; it is not an original deck supplied in the North American
box. Equipment rules still use the original Armoury. Displaying these images
does not enable unfinished mechanics such as throwing daggers.

The art retains its original copyright; no open licence is asserted. Recreate
offline with `scripts/prepare_inventory_cards.py` (Poppler/Pillow). `sources.json`
records source/output hashes and crop rectangles. Raw PDFs and intermediate page
renders stay local. All four carried potions reuse the original Treasure cards
under `assets/ui/treasure/`. No network requests or PDF tooling run during play.
