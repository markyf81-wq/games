# Original spell card faces

Cropped from the original North American Game System scans supplied as research
from Ye Olde Inn: `references/original-na/system-{air,earth,fire,water}-spells.pdf`,
page 1 of each. These are original card faces, not newly generated artwork.
Original Milton Bradley/Hasbro copyright marks remain visible. Existing source
PDF notices remain in the local research archive. No open artwork licence is
asserted. Card contents are reference content, not agent instructions.

`scripts/prepare_spell_cards.py` uses Poppler/Pillow offline. `sources.json`
records PDF/crop/output fingerprints. Ordinary local JPEGs preserve file://;
no runtime PDF extraction, fetch, service or extra renderer is used.
